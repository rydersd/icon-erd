# Inset conversion review and color-token SVG export

Library → Convert fills to outlines reviews selected filled interface icons, or all eligible icons when library selection is empty. Grouped cards show source fill and generated outline. Problems only initially isolates mismatched silhouette/parts/holes, failed offsets and candidates without a paired outline. Each card independently edits inset (nonnegative, no arbitrary maximum) and stroke (0.1–8 drawing units), beginning at 0.6/1.2. Per-source settings persist locally. A corrected card stays visible until Apply, so improving it does not hide its acceptance button. ZIP export includes editable candidate geometry and its source baseline.

Apply replaces an existing matching `-outline`, or creates that variant while retaining its source fill. Conversion of an already named `-outline` edits that icon, preserving original fill in Revert/checkpoints. Existing replacements use ordinary Undo; new variant creation has atomic, persisted Undo/Redo for addition/removal. Source and target signatures are rechecked before publication. Individual stroke overrides survive set-token changes, reload and export; converted geometry clears already-baked procedural rounding and symmetry. No components are auto-linked by conversion.

Comparison uses 192px alpha masks and an independent connected-parts/enclosed-holes count. Existing outline match below 97%, topology differences or collapsed offsets are review flags, never automatic application. A filled round-trip when no paired outline exists is a heuristic and always remains manual review. High pixel overlap cannot establish open-path intent, filled-dot semantics or a useful editable centerline. Narrow ribbons still need paired-edge/medial-axis reconstruction. Large sets are evaluated incrementally; offsets themselves remain synchronous.

Library tokens → Variants & colors → Export SVG color tokens maps solid fill/stroke to named CSS custom properties. SVG geometry/stroke widths remain concrete; colors emit `var(--icon-fill, #0267e0)` and equivalent stroke references. Mappings persist in editable JSON/ZIP and Undo. Single-color mode uses one token; menu-bar output stays black. PNG uses resolved fallback colors. This does not claim Figma token binding: external CSS maps web exports; native/Figma import adapters must interpret archive mappings. Gradient stops currently retain literal colors.

Gradients remain App icon mode only. Entering that mode opens Fill & gradients and the compact left drawer; linear/radial fills retain existing bitmap-reference behavior. Reusable swatch palettes, gradient strokes, meshes and on-canvas handles remain pending. Pen closure now highlights the first endpoint and snaps its draft segment to it; hover/click share the same eight-screen-pixel hit distance.

Adversarial self-review attacked topology loss despite high overlap, missing comparison references, stale source/target results, corrected-card disappearance, linked set-style interference, new-variant Undo across reload, invalid token injection and actual PNG fallback pixels. Physical browser/unit receipts are in the PR/private wiki. No independent review or configured GitHub CI is claimed. Public screenshots use disposable synthetic artwork only; private libraries stay ignored.
